# Data sources

Every dataset, where it comes from, how often it updates, and its known
quirks. Nothing in `data/` is committed; every series re-downloads through
the cached clients in `src/vrp_lab/data/`.

| Series | Source | Client | Frequency | Span |
|---|---|---|---|---|
| VIX daily OHLC | CBOE `VIX_History.csv` (free CDN) | `cboe.pull_vix_history` | daily EOD | 1990-01 → present |
| VX futures settles, per contract | CBOE `historical_data/VX/VX_{expiry}.csv` | `cboe.pull_vx_contract` / `pull_vx_curve` | daily EOD | **2013-05 → present** |
| SPY / SPX OHLCV | Yahoo Finance via `yfinance` | `yfinance.pull_ohlcv` | daily EOD | 1993 → present |
| DGS10, T10YIE, VIXCLS | FRED `fredgraph.csv` (no key) | `fred.pull_fred` | daily, ~1-day lag | varies |
| Options chains (live only) | Yahoo Finance | `options.fetch_live_chain` | snapshot | today only |
| Options chains (historical) | **synthetic** (BSM from SPY+VIX) | `options.synthetic_chain` | derived | = SPY span |

## Known quirks, by source

### CBOE VX contract files
- **Free archive starts ~May 2013.** The 2006–2012 era (fattest contango,
  plus 2008) requires the paid DataShop archive. All backtests here are on
  the post-2013 — i.e. *harder* — subsample; stated wherever results appear.
- One CSV per contract, keyed by final settlement date. Getting that date
  wrong 404s silently — the expiry calendar handles holiday-shifted SPX
  Fridays (Good Friday 2025-04, Juneteenth 2026-06) and is tested against
  the actual contract files.
- Rows with `settle == 0` are pre-listing placeholders and dropped.
- Files update T+1; the current front contract's file grows daily.

### FRED
- **Akamai bot protection fingerprints Python's TLS stack** and silently
  stalls `requests`/`urllib3`. The client shells out to `curl` instead
  (same workaround as the QL_MAK repo).
- Missing observations encoded as `"."` → coerced to NaN and dropped.
- DGS10 is a *yield* in percent; the backtester converts to a daily decimal
  rate. Publication lags one business day.

### Yahoo Finance
- `adj_close` is split/dividend adjusted — used for returns. Range-based
  vol estimators use the **unadjusted** OHLC (actual traded prices).
- Occasional MultiIndex column shape for single tickers — normalized in the
  client. Rare same-day revisions of the last bar; the cache freezes whatever
  was pulled first (delete `data/cache/yahoo_*.csv` to refresh).
- yfinance options chains have **no history** — the live fetcher exists for
  forward-testing only, never backtests.

### Synthetic option chains
Not data — a model. Full caveat in `METHODOLOGY.md` §8. Headline: fixed
smirk (no skew dynamics), flat term structure (30d VIX for all tenors),
BSM mids + proportional costs (real wings are wider). If institutional
access appears (WRDS/OptionMetrics IvyDB), `data/options.py` is the swap
point — everything downstream consumes the same `CHAIN_COLS` schema.
Deribit (free, real historical BTC/ETH chains) is the documented crypto
pivot if equity chains stay out of reach.

## Caching & reproducibility

All pulls cache to `data/cache/` (gitignored) — a full re-run of every
notebook and script is offline after the first pull. `data/processed/`
holds derived artifacts (`vrp_dataset.csv`, `equity_curves.csv`,
`delta_hedged_history.csv`), regenerated by:

```
python -m scripts.run_vix_carry
python -m scripts.run_delta_hedged
python -m scripts.build_notebooks
```

Validation on ingest (`data/validators.py`): schema/dtype checks, sorted
unique DatetimeIndex, **point-in-time guard** (no rows after `as_of`),
staleness detection (10+ day identical runs), bounded forward-fill (max 5
business days — longer gaps stay NaN and are logged, never bridged).
